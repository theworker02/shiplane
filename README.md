# shiplane

Ship and reshape lane text streams with deterministic transforms.

**Site:** https://theworker02.github.io/shiplane/

## Install / run

```bash
git clone https://github.com/theworker02/shiplane.git
cd shiplane
node src/cli.js
node --test
```
